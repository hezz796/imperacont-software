# Workflow: UX Design

## Objetivo

Transformar requisitos e necessidades dos usuários em uma experiência compreensível, acessível e verificável.

## Princípio

UX deve resolver necessidades reais e reduzir ambiguidades antes da implementação.

## Entrada

- product brief;
- requisitos;
- user stories;
- usuários;
- contexto;
- critérios de aceitação.

## Agente principal

`@ux-designer`

## Agentes participantes

- `@ux-researcher`
- `@product-strategist`
- `@business-analyst`
- `@reviewer`

## Skills

- `ux-research`
- `user-journeys`
- `information-architecture`
- `interaction-design`
- `prototyping`
- `accessibility-design`
- `design-system-thinking`

## Etapas

### 1. Pesquisa complementar

Quando necessário:

- validar comportamentos;
- esclarecer necessidades;
- identificar dificuldades;
- revisar hipóteses.

### 2. User journeys

Mapear:

- contexto;
- etapas;
- objetivos;
- pontos de contato;
- dificuldades;
- oportunidades.

### 3. Arquitetura da informação

Definir:

- organização;
- hierarquia;
- navegação;
- agrupamentos;
- nomenclatura.

### 4. Interação

Definir:

- fluxos;
- estados;
- ações;
- feedback;
- erros;
- exceções.

### 5. Protótipo

Criar representação suficiente para validar a experiência.

### 6. Acessibilidade

Avaliar:

- compreensão;
- navegação;
- interação;
- conteúdo;
- diferentes necessidades de usuários.

### 7. Review

Verificar:

- coerência com requisitos;
- consistência;
- acessibilidade;
- estados incompletos;
- casos de erro;
- fluxos críticos.

## Gate

Avançar quando:

- fluxos críticos estiverem definidos;
- experiência estiver suficientemente validada;
- requisitos relevantes estiverem representados;
- estados de erro forem considerados;
- acessibilidade relevante tiver sido considerada.

## Saída

Produzir:

- user journeys;
- arquitetura da informação;
- fluxos;
- wireframes ou protótipos;
- especificações de interação;
- requisitos de acessibilidade;
- decisões de UX.

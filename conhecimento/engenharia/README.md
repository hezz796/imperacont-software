# Engenharia de Software

Esta categoria contém conhecimentos utilizados para construir, modificar, manter e evoluir software de forma sustentável.

## Escopo

Pode conter conhecimentos sobre:

- estrutura e modularidade;
- coesão e acoplamento;
- manutenibilidade;
- tratamento de erros;
- dependências;
- refatoração;
- versionamento;
- gerenciamento de mudanças;
- evolução incremental;
- legibilidade;
- consistência;
- confiabilidade;
- sustentabilidade técnica.

## Relação com outras camadas

A engenharia deve ser entendida em conjunto com:

- `conhecimento/principios/`;
- `conhecimento/arquitetura/`;
- `conhecimento/qualidade/`;
- `conhecimento/seguranca/`;
- `conhecimento/devops/`;
- `conhecimento/dados/`.

As `skills` definem como executar atividades de engenharia.

Os `workflows` definem quando essas atividades devem ocorrer dentro do ciclo de desenvolvimento.

Os agentes utilizam esse conhecimento para tomar decisões e executar suas responsabilidades.

## Regra geral

O objetivo da engenharia não é produzir código da forma mais rápida possível.

O objetivo é produzir e evoluir software que seja adequado ao problema, compreensível, verificável, seguro, operável e sustentável dentro do contexto.

# Evidência antes de suposição

## Princípio

A squad deve distinguir fatos conhecidos, evidências, inferências, hipóteses, opiniões e suposições.

Quanto maior o impacto ou risco de uma decisão, maior deve ser a qualidade da evidência utilizada para sustentá-la.

## Classificação

Uma informação pode ser classificada como:

```text
FATO
EVIDÊNCIA
INFERÊNCIA
HIPÓTESE
SUPOSIÇÃO
OPINIÃO
```

Essas categorias não devem ser tratadas como equivalentes.

## Aplicação

Quando uma decisão relevante depender de uma afirmação, deve-se perguntar:

- Como sabemos disso?
- Qual é a fonte?
- A informação foi observada ou inferida?
- Existe evidência suficiente?
- Qual é o grau de incerteza?
- Qual seria o impacto de estarmos errados?

## Proporcionalidade

Nem toda decisão exige uma investigação extensa.

A profundidade da validação deve considerar:

```text
IMPACTO
+
INCERTEZA
+
RISCO
+
CUSTO DA DECISÃO
```

Quanto maiores esses fatores, maior deve ser o esforço de validação.

## Resultado esperado

A squad deve tornar a incerteza visível em vez de escondê-la atrás de afirmações aparentemente definitivas.

# Princípios

Esta pasta contém princípios fundamentais utilizados para orientar decisões de produto, engenharia, arquitetura, qualidade e evolução.

Os princípios devem funcionar como critérios de decisão, não como procedimentos operacionais.

Exemplos:

- problema antes da solução;
- evidência antes de suposição;
- simplicidade antes de complexidade;
- risco orientando esforço;
- entrega incremental;
- tecnologia como meio, não como objetivo;
- qualidade incorporada ao processo;
- segurança desde o início;
- observabilidade para sistemas relevantes;
- aprendizado contínuo.

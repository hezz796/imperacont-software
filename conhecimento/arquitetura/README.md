# Arquitetura

Esta pasta contém conhecimentos utilizados para compreender, projetar, avaliar e evoluir arquiteturas de software.

Pode incluir:

- princípios arquiteturais;
- decomposição;
- fronteiras;
- componentes;
- dependências;
- domínios;
- integrações;
- atributos de qualidade;
- decisões arquiteturais;
- trade-offs;
- resiliência;
- escalabilidade;
- interoperabilidade;
- evolução arquitetural.

A arquitetura deve permanecer orientada ao problema e aos requisitos, evitando decisões tecnológicas prematuras.

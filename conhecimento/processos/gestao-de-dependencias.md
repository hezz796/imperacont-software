# Gestão de Dependências

Dependência ocorre quando uma atividade, decisão ou resultado depende de outro elemento.

## Tipos

Dependências podem envolver:

- pessoas;
- decisões;
- requisitos;
- componentes;
- dados;
- sistemas;
- fornecedores;
- ambientes;
- aprovações;
- conhecimento.

## Identificação

Dependências importantes devem ser identificadas antes de bloquear o trabalho sempre que possível.

## Avaliação

Uma dependência deve ser avaliada quanto a:

- criticidade;
- prazo;
- risco;
- disponibilidade;
- possibilidade de substituição;
- possibilidade de paralelização.

## Estratégias

Conforme o contexto, a squad pode:

- resolver antecipadamente;
- paralelizar trabalho;
- criar uma alternativa;
- reduzir acoplamento;
- simular uma dependência;
- negociar prazo;
- alterar a sequência;
- aceitar temporariamente o bloqueio.

## Dependência versus bloqueio

Dependência é uma relação necessária.

Bloqueio é uma condição que impede ou limita o avanço.

Uma dependência pode existir sem bloquear o trabalho.

## Visibilidade

Dependências críticas devem permanecer visíveis para permitir planejamento e tomada de decisão.

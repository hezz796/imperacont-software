# Gates e Critérios de Entrada e Saída

Gates são mecanismos de controle utilizados para determinar se uma etapa possui condições suficientes para avançar.

## Critérios de entrada

Antes de iniciar uma etapa, deve existir contexto suficiente para executá-la adequadamente.

Exemplos:

- objetivo conhecido;
- contexto disponível;
- entradas necessárias presentes;
- dependências identificadas;
- restrições conhecidas.

## Critérios de saída

Antes de concluir uma etapa, devem existir evidências suficientes de que seus objetivos foram atingidos.

## Gate não é burocracia

Um gate deve existir quando reduz risco ou aumenta a qualidade da decisão.

Gates sem propósito devem ser simplificados ou removidos.

## Tipos de resultado

Um gate pode resultar em:

- aprovado;
- aprovado com ressalvas;
- bloqueado;
- devolvido para correção;
- encaminhado para nova investigação;
- risco aceito conscientemente.

## Critérios objetivos

Sempre que possível, critérios devem ser verificáveis.

Evitar critérios vagos como:

- "parece bom";
- "está pronto";
- "deve funcionar".

Preferir critérios baseados em:

- evidências;
- resultados;
- testes;
- decisões;
- requisitos;
- riscos;
- validações.

## Exceções

Uma exceção pode ser aceita quando houver justificativa clara.

A exceção não deve apagar o risco existente.

Deve registrar:

- o que foi excepcionalizado;
- motivo;
- impacto;
- responsável;
- condição para revisão.

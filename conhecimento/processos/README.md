# Processos

Esta pasta contém conhecimentos utilizados para compreender e melhorar processos de trabalho.

Pode incluir:

- gestão do fluxo;
- planejamento;
- colaboração;
- handoffs;
- definição de pronto;
- critérios de entrada e saída;
- gestão de riscos;
- melhoria contínua;
- métricas de processo;
- aprendizagem organizacional.

Os workflows executam processos; esta pasta registra conhecimentos e princípios sobre processos.

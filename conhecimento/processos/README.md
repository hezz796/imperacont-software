# Processos da Squad

## Finalidade

Esta categoria reúne o conhecimento necessário para compreender como a squad organiza, conduz, controla e melhora seu trabalho.

O objetivo não é definir comandos específicos nem substituir os workflows da squad.

Ela estabelece princípios e conceitos que orientam a execução dos processos.

## Processo não é workflow

Processo representa uma forma estruturada de organizar e controlar o trabalho.

Workflow representa a sequência operacional utilizada para executar uma determinada etapa ou fluxo.

Nesta squad:

- conhecimento explica princípios e conceitos;
- skills explicam competências de execução;
- agents representam responsabilidades;
- workflows organizam etapas de trabalho;
- commands oferecem pontos de entrada para o usuário;
- templates estruturam artefatos;
- projetos armazenam o trabalho específico de cada produto.

## Princípios

Os processos da squad devem favorecer:

- clareza;
- rastreabilidade;
- proporcionalidade;
- colaboração;
- decisões baseadas em evidências;
- controle de riscos;
- entregas incrementais;
- feedback rápido;
- reversibilidade quando possível;
- qualidade;
- segurança;
- aprendizado contínuo.

## Organização

Os conhecimentos desta categoria abrangem:

1. princípios de processos;
2. ciclo de trabalho;
3. papéis e responsabilidades;
4. tomada de decisão;
5. gestão de riscos;
6. gestão de mudanças;
7. gates;
8. handoffs;
9. rastreabilidade;
10. documentação;
11. planejamento;
12. dependências;
13. bloqueios;
14. revisão e aprovação;
15. melhoria de processos.

## Uso

Este conhecimento deve ser utilizado quando a squad precisar decidir:

- como organizar o trabalho;
- quem deve participar de uma decisão;
- quais informações precisam ser preservadas;
- quando uma etapa pode avançar;
- como controlar riscos;
- como tratar mudanças;
- como transferir trabalho entre responsabilidades;
- como identificar bloqueios;
- como melhorar o próprio processo.

## Relação com os workflows

Os workflows da pasta `workflows/` continuam sendo a referência operacional para a execução das etapas do ciclo de desenvolvimento.

Os documentos desta categoria fornecem os princípios que devem orientar esses workflows.

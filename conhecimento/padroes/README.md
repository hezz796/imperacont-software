# Padrões

Esta pasta contém padrões reconhecidos e reutilizáveis pela squad.

Um padrão deve apresentar:

- problema;
- contexto;
- forças envolvidas;
- solução ou abordagem;
- consequências;
- limitações;
- quando utilizar;
- quando evitar.

Padrões não devem ser tratados como regras universais.

A adoção de um padrão deve considerar contexto, requisitos, riscos e trade-offs.

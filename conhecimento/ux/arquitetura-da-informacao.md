# Arquitetura da Informação

## Conceito

Arquitetura da informação trata da organização, estruturação, classificação, rotulagem e navegação das informações de um produto.

Seu objetivo é ajudar as pessoas a compreender:

- onde estão;
- o que existe;
- onde encontrar algo;
- como acessar;
- como retornar;
- qual relação existe entre informações.

## Componentes

Entre os elementos relevantes estão:

- organização;
- hierarquia;
- classificação;
- nomenclatura;
- rotulagem;
- navegação;
- busca;
- relacionamentos entre conteúdos.

## Estrutura

Uma estrutura de informação deve refletir as necessidades reais dos usuários e o domínio do produto.

Estruturas excessivamente profundas podem dificultar a descoberta.

Estruturas excessivamente rasas podem gerar excesso de opções simultâneas.

## Rotulagem

Os nomes utilizados no produto devem ser compreensíveis para o público e coerentes com o contexto.

Termos técnicos internos podem não ser adequados para a interface.

## Navegação

Uma boa navegação ajuda o usuário a construir uma compreensão do espaço de informação.

Ela deve favorecer:

- previsibilidade;
- orientação;
- consistência;
- recuperação;
- compreensão do contexto.

## Busca

Quando existe grande volume de informação, mecanismos de busca podem complementar a navegação.

Busca e navegação não são necessariamente alternativas excludentes.

## Conteúdo e estrutura

Arquitetura da informação não pode ser separada completamente do conteúdo.

A estrutura deve considerar:

- tipo de informação;
- frequência de uso;
- importância;
- relações;
- vocabulário;
- contexto.

## Evolução

Arquiteturas de informação podem mudar conforme:

- o produto cresce;
- usuários mudam;
- novos domínios são incorporados;
- informações são reorganizadas;
- novos canais aparecem.

Uma arquitetura deve ser compreensível, mas também suficientemente flexível para evoluir.

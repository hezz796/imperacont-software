# Pesquisa com Usuários

## Conceito

Pesquisa com usuários é o conjunto de práticas utilizadas para compreender pessoas que utilizam ou podem utilizar um produto, serviço ou sistema.

Seu objetivo é reduzir incertezas relevantes para decisões de produto e experiência.

## O que pode ser investigado

A pesquisa pode buscar compreender:

- objetivos;
- necessidades;
- dificuldades;
- comportamentos;
- expectativas;
- motivações;
- contexto;
- restrições;
- linguagem utilizada;
- estratégias adotadas para resolver problemas;
- percepção sobre soluções existentes.

## Pesquisa não é validação de opinião

Uma pesquisa não deve ser utilizada apenas para confirmar uma solução previamente escolhida.

A investigação deve permitir que evidências contradigam hipóteses existentes.

## Contexto importa

O mesmo usuário pode apresentar comportamentos diferentes dependendo de:

- ambiente;
- dispositivo;
- frequência de uso;
- urgência;
- conhecimento;
- restrições;
- consequências de erro;
- características da tarefa.

Por isso, compreender somente características demográficas raramente é suficiente para explicar uma experiência.

## Fontes de evidência

Podem ser consideradas diferentes fontes, incluindo:

- entrevistas;
- observação;
- testes de usabilidade;
- análise de comportamento;
- dados de produto;
- suporte;
- reclamações;
- feedback;
- pesquisas existentes;
- documentação;
- contexto operacional.

Cada fonte possui limitações e deve ser interpretada de acordo com sua natureza.

## Qualidade da evidência

Uma conclusão deve considerar:

- origem da informação;
- quantidade de evidências;
- consistência;
- contexto;
- possíveis vieses;
- limitações da pesquisa;
- grau de incerteza.

Uma afirmação isolada de um usuário não deve automaticamente ser tratada como comportamento universal.

## Resultado esperado

O principal resultado de uma pesquisa não é uma coleção de opiniões.

É uma compreensão melhor fundamentada de:

- quem utiliza;
- o que tenta realizar;
- por que realiza;
- quais dificuldades encontra;
- em qual contexto;
- quais necessidades permanecem sem atendimento;
- quais hipóteses precisam ser investigadas.

## Relação com Produto

Pesquisa contribui para:

- definição de problemas;
- identificação de oportunidades;
- definição de valor;
- priorização;
- requisitos;
- hipóteses;
- métricas;
- evolução do produto.

## Relação com Design

Pesquisa fornece contexto para decisões de:

- fluxo;
- informação;
- interação;
- conteúdo;
- interface;
- acessibilidade;
- prototipação.

Pesquisa não deve ser reduzida a uma etapa anterior ao design. Evidências podem ser obtidas e utilizadas continuamente.

# Design de Interação

## Conceito

Design de interação trata de como pessoas e sistemas se comportam em relação uns aos outros durante a realização de tarefas.

O foco não está somente nos elementos visuais, mas também em:

- ações;
- estados;
- respostas;
- transições;
- regras;
- feedback;
- recuperação.

## Modelo mental

Usuários desenvolvem expectativas sobre como um sistema funciona.

Uma interface coerente ajuda a alinhar:

- o que o usuário acredita que acontecerá;
- o que o usuário faz;
- o que o sistema realmente faz.

## Estados

Elementos interativos podem possuir diferentes estados, como:

- disponível;
- selecionado;
- desabilitado;
- carregando;
- concluído;
- com erro;
- vazio;
- parcialmente preenchido.

Estados importantes devem ser considerados durante o design.

## Feedback

Uma ação relevante deve produzir uma resposta compreensível quando apropriado.

O feedback pode informar:

- confirmação;
- progresso;
- resultado;
- erro;
- bloqueio;
- próxima ação.

## Affordances

A interface deve oferecer pistas suficientes para que o usuário compreenda como interagir com os elementos.

Essas pistas podem ser:

- visuais;
- textuais;
- espaciais;
- comportamentais;
- contextuais.

## Consistência

Interações semelhantes devem possuir comportamentos previsíveis.

Inconsistências aumentam esforço cognitivo e podem gerar erros.

## Carga cognitiva

O design deve evitar exigir que o usuário mantenha na memória informações desnecessárias.

Sempre que possível, a interface pode tornar informações relevantes visíveis no momento adequado.

## Recuperação

Interações devem considerar o que acontece quando algo dá errado.

Uma experiência robusta permite, quando possível:

- corrigir;
- desfazer;
- tentar novamente;
- preservar dados;
- compreender o problema.

## Relação com regras de negócio

Interações devem refletir corretamente as regras do domínio.

Quando uma regra limita determinada ação, essa limitação precisa ser comunicada de forma compreensível.

UX e regras de negócio devem ser coerentes.

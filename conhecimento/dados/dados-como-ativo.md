# Dados como Ativo

## Conceito

Dados podem representar um ativo quando possuem utilidade relevante para:

- operação;
- produto;
- tomada de decisão;
- análise;
- conformidade;
- aprendizado;
- relacionamento com usuários.

## Valor

O valor de um dado depende de:

- qualidade;
- contexto;
- atualidade;
- disponibilidade;
- confiabilidade;
- finalidade.

Dados em grande quantidade não significam necessariamente maior valor.

## Custo

Dados também geram custos:

- coleta;
- armazenamento;
- processamento;
- proteção;
- manutenção;
- governança;
- descarte.

## Dívida de dados

Dados podem acumular problemas semelhantes à dívida técnica:

- duplicidade;
- inconsistência;
- ausência de definição;
- baixa qualidade;
- estruturas obsoletas;
- dependências difíceis de alterar.

## Decisões

Antes de coletar um novo dado, avaliar:

- por que ele é necessário;
- quem o utilizará;
- por quanto tempo;
- quais riscos existem;
- qual será o custo de manutenção.

## Princípio

Coletar dados sem finalidade clara cria custo e exposição sem necessariamente criar valor.

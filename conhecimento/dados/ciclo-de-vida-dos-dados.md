# Ciclo de Vida dos Dados

## Etapas

Dependendo do produto, os dados podem passar por:

1. criação;
2. coleta;
3. validação;
4. processamento;
5. armazenamento;
6. utilização;
7. compartilhamento;
8. alteração;
9. arquivamento;
10. descarte.

## Cada etapa

Deve-se considerar:

- finalidade;
- responsável;
- acesso;
- segurança;
- qualidade;
- retenção;
- custo.

## Retenção

Manter dados indefinidamente pode gerar:

- custo;
- risco;
- complexidade;
- exposição desnecessária.

## Arquivamento

Dados arquivados continuam sujeitos às regras aplicáveis ao seu contexto.

## Descarte

O descarte deve ser coerente com:

- finalidade;
- requisitos aplicáveis;
- dependências;
- capacidade de recuperação;
- necessidades de auditoria.

## Regra

Dados devem possuir um ciclo de vida conhecido quando sua criticidade justificar esse controle.

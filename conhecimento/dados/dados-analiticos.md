# Dados Analíticos

## Objetivo

Dados analíticos apoiam compreensão, avaliação e tomada de decisão.

## Finalidade

Antes de criar uma análise, identificar:

- pergunta;
- decisão;
- indicador;
- público;
- contexto.

## Qualidade

Indicadores devem possuir definições claras.

É necessário compreender:

- origem;
- cálculo;
- período;
- filtros;
- limitações.

## Métrica não é verdade absoluta

Uma métrica representa determinada perspectiva do sistema.

Sua interpretação depende do contexto.

## Dados operacionais e analíticos

Dados utilizados para operação e dados utilizados para análise podem possuir requisitos diferentes.

## Consistência semântica

Indicadores relevantes devem possuir definições consistentes.

## Evolução

Métricas e modelos analíticos devem ser revisados quando:

- o produto muda;
- o comportamento muda;
- a pergunta muda;
- a definição deixa de representar o objetivo.

## Resultado

Dados analíticos devem apoiar decisões, não apenas produzir dashboards.

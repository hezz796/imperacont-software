# Qualidade de Dados

## Objetivo

Dados devem ser adequados à finalidade para a qual são utilizados.

## Dimensões

Dependendo do contexto, qualidade pode envolver:

- exatidão;
- completude;
- consistência;
- atualidade;
- validade;
- unicidade;
- integridade;
- confiabilidade.

## Qualidade é contextual

Um dado pode ser adequado para uma finalidade e inadequado para outra.

## Origem

A qualidade deve ser analisada desde a origem.

Corrigir problemas somente no destino pode ocultar a causa.

## Validação

Validações devem ocorrer nos pontos apropriados do fluxo.

## Monitoramento

Quando a qualidade for crítica, devem existir mecanismos para identificar degradação.

## Dados inválidos

A estratégia deve definir o que fazer quando dados não atendem aos critérios esperados:

- rejeitar;
- corrigir;
- sinalizar;
- isolar;
- encaminhar para tratamento.

## Resultado

Qualidade de dados deve ser tratada como requisito contínuo, não como limpeza pontual.

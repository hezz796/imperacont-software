# Princípios de Dados

## Princípios fundamentais

### Finalidade

Todo dado relevante deve possuir uma finalidade compreensível.

### Qualidade

Dados utilizados pelo produto devem possuir qualidade compatível com sua finalidade.

### Integridade

Relacionamentos e regras importantes devem ser preservados.

### Consistência

O significado e o estado dos dados devem ser coerentes dentro do contexto definido.

### Rastreabilidade

Quando necessário, deve ser possível compreender:

- origem;
- transformação;
- uso;
- alteração;
- destino.

### Minimização

Não coletar ou armazenar dados sem necessidade justificável.

### Segurança

Acesso e tratamento devem ser proporcionais à sensibilidade e criticidade.

### Governança

Responsabilidades sobre dados devem ser claras.

### Evolutividade

Modelos e estruturas devem permitir evolução sem comprometer desnecessariamente dados existentes.

### Recuperabilidade

Dados críticos devem possuir mecanismos adequados de backup, restauração e recuperação.

## Dados não são apenas armazenamento

Uma arquitetura de dados inclui também:

- significado;
- regras;
- propriedade;
- fluxo;
- transformação;
- acesso;
- ciclo de vida.

## Resultado

A qualidade de uma solução de dados deve ser avaliada pela capacidade de sustentar corretamente o produto e sua evolução.

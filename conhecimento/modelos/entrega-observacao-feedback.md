# Entrega, Observação e Feedback

## Estrutura

```text
ENTREGA
   ↓
OBSERVAÇÃO
   ↓
INTERPRETAÇÃO
   ↓
FEEDBACK
   ↓
DECISÃO
   ↓
NOVA AÇÃO
```

## Entrega

Uma mudança é disponibilizada para uso ou avaliação.

## Observação

São coletados sinais sobre comportamento, qualidade, operação e resultados.

## Interpretação

Os dados são analisados no contexto.

## Feedback

Inclui informações provenientes de:

- usuários;
- operação;
- métricas;
- incidentes;
- suporte;
- testes;
- negócio.

## Decisão

A squad determina se deve:

- manter;
- corrigir;
- investigar;
- evoluir;
- reverter;
- interromper.

## Princípio

Feedback não deve ser automaticamente convertido em funcionalidade.

Primeiro deve ser compreendido.

Pode representar:

- problema;
- sintoma;
- preferência;
- defeito;
- oportunidade;
- hipótese;
- solicitação de solução.

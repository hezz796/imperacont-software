# Contexto, Problema e Objetivo

## Estrutura

```text
CONTEXTO
   ↓
PROBLEMA
   ↓
OBJETIVO
```

## Contexto

Define as condições nas quais a situação existe.

Pode incluir:

- usuários;
- ambiente;
- processos;
- restrições;
- histórico;
- sistemas existentes;
- condições externas.

## Problema

Define a situação que precisa ser compreendida ou resolvida.

## Objetivo

Define o resultado desejado.

## Perguntas

### Contexto

- Onde o problema ocorre?
- Quem é afetado?
- Quais restrições existem?
- O que já existe?

### Problema

- O que está acontecendo?
- Qual impacto existe?
- Para quem?
- Há evidências?

### Objetivo

- O que precisa melhorar?
- Como saberemos que melhorou?
- Quais limites existem?

## Princípio

Não começar pela pergunta:

> "Qual sistema devemos construir?"

Antes disso, compreender:

> "Qual situação precisa mudar e por quê?"

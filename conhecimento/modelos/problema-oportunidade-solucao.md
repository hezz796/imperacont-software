# Problema, Oportunidade e Solução

Esses conceitos são relacionados, mas não equivalentes.

## Relação

```text
PROBLEMA
   ↓
OPORTUNIDADE
   ↓
POSSÍVEIS SOLUÇÕES
```

## Problema

É uma situação indesejada ou necessidade não atendida.

## Oportunidade

É uma possibilidade de gerar valor ou melhorar uma situação.

## Solução

É uma proposta concreta para modificar a situação.

## Exemplo

```text
Problema:
O usuário demora para concluir uma tarefa.

Oportunidade:
Reduzir o esforço necessário para concluí-la.

Soluções possíveis:
- reorganizar o fluxo;
- automatizar uma etapa;
- melhorar informações;
- alterar o processo.
```

## Importância

Uma única solução pode não ser a única resposta possível.

A squad deve evitar assumir que a solução sugerida inicialmente é necessariamente a melhor.

## Pergunta central

Antes de aceitar uma solução proposta:

> "Qual problema essa solução pretende resolver?"

# Modelos

Esta pasta contém modelos mentais, modelos conceituais e estruturas de raciocínio que podem ser utilizados pela squad.

Podem incluir:

- modelos de decisão;
- modelos de análise;
- modelos de risco;
- modelos de sistemas;
- modelos de ciclo de vida;
- modelos de maturidade;
- modelos de priorização;
- modelos de avaliação.

Modelos são instrumentos de raciocínio e não devem ser aplicados mecanicamente fora do contexto para o qual foram definidos.

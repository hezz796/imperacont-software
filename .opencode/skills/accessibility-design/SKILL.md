# Accessibility Design

## Objetivo

Garantir que a experiência seja utilizável pelo maior número possível de pessoas, considerando diferentes capacidades e contextos.

## Princípio

Acessibilidade deve ser considerada desde o design, não apenas como uma verificação final.

## Dimensões

Considerar:

- visão;
- audição;
- mobilidade;
- cognição;
- linguagem;
- atenção;
- diferentes dispositivos;
- diferentes métodos de entrada;
- diferentes condições ambientais.

## Interface

Avaliar:

- contraste;
- tamanho e legibilidade;
- hierarquia;
- foco;
- navegação por teclado;
- identificação de elementos;
- mensagens;
- estados;
- alternativas para conteúdo não textual.

## Interação

Garantir que ações importantes não dependam exclusivamente de:

- cor;
- precisão motora;
- áudio;
- gestos complexos;
- tempo extremamente limitado.

## Conteúdo

Utilizar:

- linguagem clara;
- títulos adequados;
- instruções compreensíveis;
- mensagens de erro úteis;
- identificação consistente.

## Formulários

Considerar:

- associação entre rótulos e campos;
- indicação de erros;
- orientação para correção;
- ordem de navegação;
- preservação dos dados.

## Responsividade

Considerar diferentes:

- tamanhos de tela;
- orientações;
- métodos de entrada;
- condições de uso.

## Validação

Combinar, quando possível:

- avaliação especializada;
- testes automatizados;
- testes manuais;
- testes de teclado;
- testes com tecnologias assistivas;
- testes com usuários.

Ferramentas automatizadas não substituem avaliação humana.

## Saída esperada

Produzir:

1. requisitos de acessibilidade;
2. decisões de design;
3. padrões de interação;
4. estados acessíveis;
5. critérios de validação;
6. problemas encontrados;
7. recomendações;
8. pendências.

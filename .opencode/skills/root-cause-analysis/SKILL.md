# Root Cause Analysis

## Objetivo

Identificar causas relevantes de um problema e orientar ações corretivas sustentáveis.

## Princípio

Corrigir o sintoma pode restaurar o funcionamento, mas compreender a causa reduz a probabilidade de recorrência.

## Processo

1. Descrever o problema.
2. Delimitar o impacto.
3. Coletar evidências.
4. Reconstruir a sequência de eventos.
5. Identificar fatores contribuintes.
6. Investigar causas.
7. Validar hipóteses.
8. Definir ações corretivas.
9. Implementar ações.
10. Verificar se o problema foi efetivamente tratado.

## Técnicas

Podem ser utilizadas:

- análise de linha do tempo;
- cinco porquês;
- árvore de causas;
- análise de falhas;
- correlação de eventos;
- comparação entre comportamento esperado e observado.

## Regras

- Não concluir causa sem evidência suficiente.
- Diferenciar causa raiz de fator contribuinte.
- Evitar atribuição prematura de culpa.
- Considerar fatores técnicos e processuais.
- Validar se a ação realmente reduz recorrência.

## Saída

Produzir:

- problema;
- impacto;
- evidências;
- linha do tempo;
- causas;
- fatores contribuintes;
- ações;
- validação.

Analise o contexto:

$ARGUMENTS

Produza um plano técnico de implementação.

Considere:

- requisitos;
- user stories;
- arquitetura;
- dependências;
- contratos;
- dados;
- segurança;
- testes;
- observabilidade;
- riscos;
- sequência de implementação.

O plano deve dividir o trabalho em unidades pequenas e verificáveis.

Para cada unidade, identifique quando aplicável:

- objetivo;
- escopo;
- dependências;
- alterações esperadas;
- testes;
- critérios de conclusão;
- riscos.

Não implemente o código.

Ao final, apresente o plano em ordem de execução.
